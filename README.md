## 📌 Descrição

Este é um projeto de uma landing page moderna chamada **Brainwave**, desenvolvida utilizando **React** e **Tailwind CSS**, baseado em um [projeto do JavaScript Mastery](https://www.youtube.com/watch?v=B91wc5dCEBA&t=1307s).

A aplicação apresenta uma interface futurista e responsiva para uma plataforma de chat com Inteligência Artificial, destacando recursos como automação inteligente, produtividade, integração com ferramentas e planos de assinatura.

O projeto está sendo construído com foco em:

- Componentização reutilizável
- Estrutura escalável
- Código limpo
- Boas práticas com React
- Customização com Tailwind

---

## 🚀 Características do Projeto

- Layout totalmente responsivo (mobile-first)
- Menu mobile com controle de scroll
- Animações e efeitos visuais modernos
- Uso de gradientes personalizados
- Uso de componentes reutilizáveis
- Organização por seções

### 📂 Seções implementadas / em desenvolvimento:

- ✅ Header com navegação responsiva
- ✅ Hero Section
- ✅ Benefits
- ✅ Collaboration
- ✅ Services
- ✅ Pricing
- ✅ Roadmap
- ✅ Footer

---

## 🛠️ Tecnologias Utilizadas

- React
- Tailwind CSS
- Vite
- React Router
- Demais bibliotecas:
  - scroll-lock: bloqueia e libera o scroll da página. Usado no menu mobile.
  - react-just-parallax: cria efeito de parallax em elementos React conforme o usuário rola a página.

## ▶️ Como Rodar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/seuuser/brainwave.git
```
<br>

2. Entre na pasta do projeto: <br>
```bash
cd brainwave
```
<br>

   
3. Instale as dependências: <br>
```bash
npm install
```
<br>

4. Inicie o servidor de desenvolvimento: <br>
```bash
npm run dev
```
<br>

5. Abra o navegador no endereço que o Vite indicar - geralmente: <br>
```bash
http://localhost:5173
```
